# AI Tool Usage Disclosure

> **Draft — review and adjust to match exactly how you worked before submitting.**

**Tool used:** Claude Code (Anthropic's Claude, in the Claude desktop app).

**How I used it:**
- **Planning:** I reviewed the brief with the assistant to list requirements and deliverables, identify ambiguities (e.g. how students authenticate) and decide on assumptions.
- **API contract:** I defined the API contract (`docs/API.md`) first and used it as the single source of truth for both sides.
- **Code generation:** the backend and the mobile app were generated by AI agents working in parallel from that contract and detailed specifications I set (architecture, folder structure, security requirements, error format, test scenarios, UX states).
- **Verification:** I ran and checked the results myself — backend type checking and the integration test suite against a real PostgreSQL database, mobile type checking and unit tests, and the app end-to-end on an Android emulator against the local backend.
- **Documentation:** README, API docs and this approach document were drafted with the assistant and reviewed by me.

**Ownership:** I reviewed the code and can explain and justify the design decisions, including the auth flow (Google ID token → own JWT + rotating refresh tokens), the database schema and constraints, authorization rules, and the mobile state-management approach.
